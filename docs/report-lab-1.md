# Звіт з лабораторної роботи 1. Середовище і перша сторінка

**Репозиторій:** https://github.com/dreyliky/course-project
**Опублікована сторінка:** https://dreyliky.github.io/course-project/

## 1. Мета роботи

Налаштувати робоче середовище веброзробника, опанувати базовий цикл роботи з
Git і опублікувати першу сторінку курсового проєкту в мережі.

## 2. Склад середовища

| Компонент | Версія / опис |
| --- | --- |
| Операційна система | macOS 27 |
| Система контролю версій | Git 2.49.0 |
| Редактор коду | Visual Studio Code |
| Локальний сервер | вбудований модуль `http.server` (Python 3.13) |
| Хостинг | GitHub Pages |

Єдині правила відступів і кодування винесено у файл `.editorconfig`, щоб
форматування не залежало від налаштувань конкретного редактора.

## 3. Налаштування Git

Після встановлення Git задано дані автора, які потрапляють у кожен коміт:

```
git config --global user.name "dreyliky"
git config --global user.email "dreyliky@gmail.com"
git config --global init.defaultBranch main
```

Основну гілку одразу названо `main`, бо саме з неї публікується GitHub Pages.

## 4. Створення репозиторію

```
git init
git remote add origin https://github.com/dreyliky/course-project
git add .
git commit -m "chore: set up repository structure"
git push -u origin main
```

У `.gitignore` внесено те, що не повинно потрапляти у віддалений репозиторій:
залежності (`node_modules/`), результати збірки, логи, службові файли
операційної системи та налаштування редакторів. Це зменшує розмір репозиторію
і прибирає зайві розбіжності між учасниками з різними редакторами.

## 5. Структура проєкту

```
.
├── assets/
│   └── css/
│       └── style.css    # стилі сторінки
├── docs/
│   └── report.md        # звіт з лабораторної роботи
├── .editorconfig
├── .gitignore
├── index.html           # стартова сторінка
└── README.md
```

Розмітка, стилі та документація рознесені по окремих каталогах. Поки сторінка
одна, усі стилі тримаються в одному файлі `style.css` — ділити його на частини
немає сенсу, це робитиметься тоді, коли сторінок стане більше.

## 6. Прийняті рішення

**Окремий файл стилів.** Стилі винесено з розмітки у зовнішній файл, тому
оформлення можна змінювати, не чіпаючи HTML, а браузер кешує його окремо.

**Кольори через CSS-змінні.** П'ять кольорів оголошено в `:root` і далі
використовуються за назвами. Щоб змінити палітру сторінки, достатньо
відредагувати одне місце, а не шукати значення по всьому файлу.

**Семантична розмітка.** Використано `header`, `nav`, `main`, `section`,
`footer` і заголовки за рівнями: структура сторінки зрозуміла і браузеру, і
зчитувачам екрана, а не тримається на самих лише `div`.

**Списки замість ручної нумерації.** План розвитку оформлено тегом `ol`, тому
номери етапів проставляє браузер — при додаванні нового пункту нічого
перенумеровувати вручну не доведеться.

**Адаптивність.** Ширина вмісту обмежена значенням `max-width`, тому на великих
екранах рядки не розтягуються. Один медіазапит на ширині до 600 px перебудовує
шапку у стовпчик і зменшує заголовок.

**Без збірки.** На цьому етапі проєкт складається зі статичних файлів, тому
інструменти збірки не додавалися: вони з'являться тоді, коли справді будуть
потрібні.

## 7. Історія комітів

Робота розбита на коміти за змістом зміни, а не за часом. Повідомлення написані
за угодою Conventional Commits (`chore`, `feat`, `style`, `docs`), тому за
історією видно, що саме змінювалось на кожному кроці:

1. `chore: set up repository structure`
2. `feat: add markup of the start page`
3. `style: add base styles for the start page`
4. `feat: add about, roadmap and technologies sections`
5. `style: adapt the page for small screens`
6. `docs: add report for lab work 1`

## 8. Публікація через GitHub Pages

У налаштуваннях репозиторію (**Settings → Pages**) як джерело обрано
**Deploy from a branch**, гілка `main`, каталог `/ (root)`. Після збереження
GitHub зібрав сайт і видав адресу https://dreyliky.github.io/course-project/.

Файл `index.html` лежить у корені репозиторію, тому додаткове налаштування не
потрібне. Кожен наступний `git push` в `main` автоматично оновлює опубліковану
версію.

## 9. Перевірка результату

- Сторінка відкривається локально (`python3 -m http.server`) і за публічною адресою.
- Перевірено вигляд на ширині 375 px і на десктопі.
- Усі посилання навігації ведуть до відповідних секцій.
- Консоль браузера без помилок, сторонні ресурси не завантажуються.

## 10. Висновки

Налаштовано робоче середовище, засвоєно базовий цикл роботи з Git
(`init` → `add` → `commit` → `push`) і опубліковано стартову сторінку курсового
проєкту через GitHub Pages. Закладена структура каталогів розрахована на
подальше зростання: наступні лабораторні додаватимуть сторінки й
функціональність без переписування вже наявного коду.
