Курсовий проєкт з вебтехнологій

Репозиторій, у якому крок за кроком збирається навчальний вебпроєкт. На цьому етапі налаштовано середовище розробки, закладено структуру каталогів і опубліковано першу сторінку через GitHub Pages.

Репозиторій на GitHub

Про проєкт

Що зроблено на етапі налаштування середовища:

  • встановлено й налаштовано Git та редактор коду;
  • створено репозиторій на GitHub і зв'язано його з локальним;
  • закладено структуру каталогів для розмітки, стилів і звітів;
  • опубліковано стартову сторінку через GitHub Pages.

План розвитку

Етапи, через які проєкт проходитиме протягом курсу:

  1. Середовище і перша сторінка виконано
  2. Семантична та адаптивна верстка
  3. Інтерактивність на JavaScript
  4. Робота з формами та даними
  5. Збірка та оптимізація

Технології

  • HTML5
  • CSS3
  • Git та GitHub
  • GitHub Pages
  • Visual Studio Code
