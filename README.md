# Курсовий проєкт

Навчальний курсовий проєкт з вебтехнологій. Репозиторій розвивається від
лабораторної до лабораторної: кожна наступна тема нашаровується на вже наявний
код, тому структура закладається з розрахунку на зростання.

Предметна область проєкту поки не зафіксована — перші лабораторні роботи
присвячені середовищу, розмітці та доступності, тому наповнення сторінок
описове.

**Опубліковано:** https://dreyliky.github.io/course-project/

## Сторінки

| Сторінка | Файл | Призначення |
| --- | --- | --- |
| Головна | `index.html` | короткий опис проєкту та його поточного стану |
| Про проєкт | `about.html` | склад виконаної роботи, план розвитку, технології |
| Зворотний зв'язок | `contact.html` | форма з перевіркою на боці браузера |

## Структура

```
.
├── assets/
│   └── css/
│       ├── tokens.css       # дизайн-токени: кольори, розміри, відступи
│       └── style.css        # стилі всіх сторінок
├── docs/
│   ├── report-lab-1.md      # звіт: середовище і перша сторінка
│   ├── report-lab-2.md      # звіт: семантика і форми
│   ├── report-lab-3.md      # звіт: Flexbox і Grid
│   └── report-lab-4.md      # звіт: адаптивність і дизайн-система
├── about.html
├── contact.html
└── index.html
```

Розкладка побудована на CSS Grid (каркас сторінки, два стовпці з бічною
панеллю, сітка карток) і Flexbox (шапка, нутрощі карток, ряд тегів).
Вбудованих стилів у розмітці немає.

Усі кольори, відступи й розміри задані токенами в `assets/css/tokens.css`,
решта стилів лише звертається до них. Темна тема вмикається за системним
налаштуванням і перевизначає тільки кольорові токени. Інтерфейс розрахований
на три класи пристроїв з межами 600 і 1024 px.

Шапка, бічна панель і підвал поки повторюються в кожному файлі: засобами самого
HTML це не вирішується. Дублювання приберу на етапі, де в проєкті з'явиться
збірка сторінок.

## Локальний запуск

Проєкт складається зі статичних файлів і не потребує збірки. Достатньо відкрити
`index.html` у браузері або підняти локальний сервер:

```
python3 -m http.server 8000
```

Сторінки будуть доступні за адресою http://localhost:8000.

## Публікація

Сторінки публікуються через GitHub Pages з гілки `main` (корінь репозиторію).
Кожен запис в основну гілку оновлює опубліковану версію.
