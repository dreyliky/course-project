# Курсовий проєкт

Навчальний курсовий проєкт з вебтехнологій. Репозиторій розвивається від
лабораторної до лабораторної: кожна наступна тема нашаровується на вже наявний
код, тому структура закладається з розрахунку на зростання.

Предметна область проєкту на цьому етапі навмисно не зафіксована — лабораторна
робота 1 присвячена налаштуванню середовища, роботі з Git і публікації стартової
сторінки, тому наповнення поки що описове.

## Структура

```
.
├── assets/
│   └── css/            # стилі сторінки
├── docs/               # звіти з лабораторних робіт
└── index.html          # стартова сторінка проєкту
```

## Локальний запуск

Проєкт складається зі статичних файлів і не потребує збірки. Достатньо відкрити
`index.html` у браузері або підняти локальний сервер:

```
python3 -m http.server 8000
```

Сторінка буде доступна за адресою http://localhost:8000.

## Публікація

Стартова сторінка публікується через GitHub Pages з гілки `main` (корінь
репозиторію).
