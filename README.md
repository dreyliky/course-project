# Курсовий проєкт

Навчальний курсовий проєкт з вебтехнологій. Репозиторій розвивається від
лабораторної до лабораторної: кожна наступна тема нашаровується на вже наявний
код, тому структура закладається з розрахунку на зростання.

Предметна область проєкту поки не зафіксована — лабораторні роботи присвячені
середовищу, розмітці, доступності, розкладці та інструментам, тому наповнення
сторінок описове.

**Опубліковано:** https://dreyliky.github.io/course-project/

## Сторінки

| Сторінка          | Файл            | Призначення                                            |
| ----------------- | --------------- | ------------------------------------------------------ |
| Головна           | `index.html`    | короткий опис проєкту та його поточного стану          |
| Про проєкт        | `about.html`    | склад виконаної роботи, план розвитку, технології      |
| Активність        | `activity.html` | історія комітів із GitHub API, фільтр і модальне вікно |
| Зворотний зв'язок | `contact.html`  | форма з перевіркою на боці браузера                    |

## Структура

```
.
├── .github/workflows/
│   └── deploy.yml           # перевірки та публікація на GitHub Pages
├── docs/                    # звіти з лабораторних робіт
├── src/
│   ├── scripts/             # клієнтська логіка на TypeScript
│   │   ├── api.ts           # запит до GitHub API
│   │   ├── commits.ts       # список комітів, стани, фільтр
│   │   ├── dom.ts           # пошук елементів із перевіркою
│   │   ├── format.ts        # форматування дати
│   │   ├── main.ts          # точка входу сторінок
│   │   ├── modal.ts         # модальне вікно
│   │   └── theme.ts         # перемикач теми
│   ├── styles/
│   │   ├── tokens.css       # дизайн-токени
│   │   └── style.css        # стилі сторінок
│   └── types/               # типи предметної області
│       ├── commit.ts
│       ├── state.ts
│       └── theme.ts
├── about.html
├── activity.html
├── contact.html
├── index.html
├── eslint.config.js
├── tsconfig.json
└── vite.config.ts
```

Сторінки лежать у корені, бо Vite розглядає HTML як точки входу й шукає їх там.

## Запуск

```
npm install
npm run dev
```

Сервер розробки підніметься на http://localhost:5173/course-project/.

## Команди

| Команда                | Що робить                                   |
| ---------------------- | ------------------------------------------- |
| `npm run dev`          | сервер розробки з гарячим оновленням        |
| `npm run build`        | перевірка типів і продакшн-збірка у `dist/` |
| `npm run preview`      | локальний перегляд зібраної версії          |
| `npm run typecheck`    | перевірка типів без збірки                  |
| `npm run lint`         | ESLint із правилами, що спираються на типи  |
| `npm run format`       | форматування Prettier                       |
| `npm run format:check` | перевірка форматування без змін             |

## Публікація

Кожен запис у гілку `main` запускає workflow `.github/workflows/deploy.yml`:
він перевіряє типи, запускає ESLint і Prettier, збирає проєкт і публікує
вміст `dist/` на GitHub Pages. Джерело публікації в налаштуваннях репозиторію —
**GitHub Actions**.
