Активність

Останні тридцять комітів репозиторію. Дані завантажуються під час відкриття сторінки з публічного GitHub API, тому список завжди показує поточний стан роботи.

Звідки дані

Запит іде до публічного GitHub API без авторизації. Ліміт — шістдесят запитів на годину з однієї адреси; при його перевищенні сторінка покаже відповідне повідомлення.
