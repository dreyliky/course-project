Про проєкт

Предметна область проєкту поки не зафіксована: перші лабораторні роботи присвячені середовищу, розмітці та доступності, тому наповнення сторінок описове. Структура закладається так, щоб тему можна було додати пізніше без переписування коду.

Що зроблено

  • налаштовано Git, редактор коду та репозиторій на GitHub;
  • закладено структуру каталогів для розмітки, стилів і звітів;
  • стартову сторінку опубліковано через GitHub Pages;

План розвитку

Етапи, через які проєкт проходитиме протягом курсу:

  1. Середовище і перша сторінка виконано
  2. Семантика і форми
  3. Інтерактивність на JavaScript
  4. Робота з даними
  5. Збірка та оптимізація

Технології

  • HTML5 — семантична розмітка та вбудована перевірка форм
  • CSS3 — оформлення сторінок і станів полів
  • Git та GitHub — контроль версій
  • GitHub Pages — публікація
  • Visual Studio Code — редактор коду
