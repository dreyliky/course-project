Про проєкт

Предметна область проєкту поки не зафіксована: перші лабораторні роботи присвячені середовищу, розмітці, доступності та розкладці, тому наповнення сторінок описове. Структура закладається так, щоб тему можна було додати пізніше без переписування коду.

Що зроблено

  • налаштовано Git, редактор коду та репозиторій на GitHub;
  • закладено структуру каталогів для розмітки, стилів і звітів;
  • сторінки опубліковано через GitHub Pages;
  • форму зворотного зв'язку перевіряє сам браузер, без скриптів;
  • розкладку сторінок побудовано на Grid і Flexbox.

План розвитку

Етапи, через які проєкт проходитиме протягом курсу:

  1. Середовище і перша сторінка виконано
  2. Семантика і форми виконано
  3. Flexbox і Grid виконано
  4. Інтерактивність на JavaScript
  5. Робота з даними
  6. Збірка та оптимізація

Як побудовано розкладку

  • Каркас сторінки

    Grid у три рядки: шапка, вміст, підвал. Середній рядок розтягується, тому підвал притиснутий донизу навіть на короткій сторінці.

  • Вміст і бічна панель

    Grid у дві колонки. На вузькому екрані колонки стають одна під одною, бічна панель іде після основного тексту.

  • Сітка карток

    Кількість колонок браузер добирає сам під ширину екрана — окремі точки зламу для цього не потрібні.

  • Вирівнювання

    Flexbox відповідає за шапку, ряд тегів і внутрішню будову картки: посилання притиснуте до низу незалежно від довжини тексту.
